00Тема, которая сейчас показана

5 акцентов × 2 режима = 10 тем, маппинг themes: Record<string, Theme>. Выбор режима — 'light' | 'dark' | 'system' (system берёт useColorScheme()), акцент и режим хранятся в AsyncStorage (@fittracker_theme_mode, @fittracker_theme_accent).

Дефолт в ThemeProvider: режим system, акцент purple. Алиасы обратной совместимости: lightTheme = purpleLightTheme, darkTheme = purpleDarkTheme.

01Цвета — ThemeColors (23 токена)

Клик по плашке копирует значение. В столбце «контраст» — отношение к surface текущей темы (для токенов текста), чтобы сразу видеть AA-статус.

02Градиенты — ThemeGradients

Каждая тема даёт свою пару. Рендерятся через expo-linear-gradient, угол — «top → bottom» как показано.

Статические GRADIENTS в конце theme.ts — фиолетовая светлая пара, оставлены для обратной совместимости. Текст поверх hero фиксированно белый: ON_STATIC_GRADIENT_COLOR = '#FFFFFF', а не textInverse.

08Адаптивность — scale() и fontScale()

База вёрстки 375 px; portrait зафиксирован в app.json, поэтому ширина читается один раз при загрузке модуля.

320 px375 px (база)414 px
×0.853×1.000×1.104
  • scale(size) = round(width / 375 × size) — размеры, иконки, отступы, радиусы
  • fontScale(size) = round(width / 375 × size × 0.95 + size × 0.05) — шрифты: сжимаются мягче, чтобы на широких экранах текст не рос несоразмерно
  • withAlpha(hex, a) — типобезопасная прозрачность вместо конкатенации строк
Макеты в Фигме держим на 375 px (база формул). Для 320 и 414 — отдельные фреймы только там, где меняется перенос строк.

09Как это перенести в Фигму

Ниже — что во что ложится в Фигме. Рядом лежит design/tokens.json — он генерируется скриптом node design/build-tokens.js прямо из theme.ts / typography.ts / semanticColors.ts, поэтому значения в нём не переписываются руками. Ставишь в Фигму плагин Tokens Studio → Import JSON → получаем коллекцию переменных с 10 режимами.

Что в tokens.json

СекцияСодержимое
theme.color.*23 токена, у каждого $value — объект из 10 режимов (purple-light … pink-dark) = Figma Variables c modes
theme.gradient.*6 градиентов × 10 режимов, пары стопов
theme.typography.*16 стилей: fontFamily / fontSize / lineHeight / fontWeight (числом) / letterSpacing / textCase
theme.space · radius · shadowSPACING, BORDER_RADIUS, SHADOWS (в описании тени — opacity и android-elevation)
theme.layout · motionбаза 375, 85% листа, tap target 44, длительности и spring-параметры
flatThemesто же плоским списком: по 23 цвета на каждую из 10 тем — для импортёров без поддержки режимов
categorical11 групп вне тем: уровни, макросы, тяжесть, зоны тела, фарма, тренды, toast, графики, анатомич. карта, мышцы
staticsGRADIENTS (fallback) и ON_STATIC_GRADIENT_COLOR
JSON можно не импортировать: в Фигме Variables → Edit styles не принимает design-tokens нативно, поэтому путь — плагин (Tokens Studio for Figma, или любой DTCG-импортёр). Альтернатива без плагинов — перенести значения из этой страницы вручную по таблице ниже: имена и значения уже разложены, остаётся их продублировать в Variables/Styles.

Токены, которые стоит переносить как есть, без «улучшения»: textTertiary === textSecondary во всех светлых темах (зафиксировано под WCAG AA), primaryLight в тёмных темах — это тёмная заливка, а не светлая (имя историческое), и overlay в Кибере (тёмная) — 0.8, а не 0.7. Если в Фигме это «починят», макеты разойдутся с приложением.
