**Оценка соответствия: ниже A (частично A).** Наиболее массовые провалы Level A: 1.1.1 (body map, безымянные цели), 1.4.1 (color-only в SetsGrid), 2.2.2 (неуправляемое движение), 3.3.1/4.1.2 (ошибки/состояния). До AA — главный gap: палитры «Энергия/Профи/Кибер/Закат» light в первичных поверхностях (CTA/текст).
Топ-3 по «исправить сегодня»: A11Y-1/2/3/4/5 одним пакетом `on-*` + `*-text` токенов (S–M, трогает только constants/theme.ts + semanticColors.ts); A11Y-6+9 (связка label/ошибок и live regions, S); A11Y-7 (useReduceMotion хук, M — пересекается с отложенным FZ-8, делать вместе).

Юридический риск: приложение consumer-fitness, без гос-обязательств; основной периметр — ADA-подобные претенции к consumer-приложениям и будущий EAA (если веб-порт публикуется публично) — **требует проверки法务**, статический аудит это только техническая подготовка.

## Проверено и соответствует (не ре-аудитировать)

- **Контраст базовых токенов**: textPrimary 12.1–18.4:1, textTertiary light 4.51–4.83:1, все dark-темы primary/secondary ≥5.6:1 (кроме A11Y-14); семантические text-цвета в dark 5.3–10.1:1 — исправление textTertiary из DS-1 подтверждено кодом (theme.ts:81,120,162,201,243,282,324,363,405,444).
- **Tab bar**: role="tab" + `accessibilityState.selected` + label из title-роутеров (CustomTabBar.tsx:114–120, _layout.tsx:29–34); размер ячейки ≈56×54 ≥44; подписи убраны осознанно (§3.6, label компенсирует).
- **PillToggle (DS-3)** и степперы ExerciseSettingsSheet: 44×44, смысловые label («Увеличить целевой RPE»), selected-состояния (ExerciseSettingsSheet.tsx:67–262, :262 label с «, выбрано»).
- **StatusCard**: 19 accessibility-PROP — pips с «Оценить готовность на N из 5», hint'ы, label чипов цикла/травм/прогноза (StatusCard.tsx:167–538); RpeEditor, PainMorphEditor, WarmupExerciseCard (checkbox role + state + label с именем), WorkoutTimer/SkipWorkoutSheet — label/state на месте (DS-1 Этап H4 подтверждён).
- **ON_MEDIA_TEXT** `#FFFFFF` на скриме 0.55: worst-case (чистое белое изображение) 4.74:1 — прохождение AA (формализовано CTR-4, theme.ts:527–535).
- **Disabled-кнопки** (textTertiary на border 3.9:1) — exempt из 1.4.3 (неактивные компоненты).
- **feedback.ts**: на нативе — системный Alert (полностью доступен AT; web-часть — A11Y-20).
- **Списки/FlashList справочника**: ExerciseRow.tsx:41–42 role+label с именем упражнения; текстовые кнопки («Сбросить», сегменты workouts.tsx:232–234) — name из текста; порядок обхода = визуальный (логичный).
- **inputMode/keyboardType**: decimal-pad/number-pad на всех числовых полях, email-address на почте — набор чисел корректный; не хватает только autoComplete (A11Y-16).
- Ошибки формы валидируются текстом, не только цветом (feedback.alert / AppInput error-текст) — сама идея 3.3.1 соблюдена, ломается озвучка (A11Y-6/9).

## Не проверено статически (обязательно на устройстве)

1. Реальное поведение VoiceOver/TalkBack: обход шторок, озвучка live-обновлений (SetsGrid accessibilityLiveRegion :1228 — не слушал), произношение `accessibilityValue` — не использован нигде, поведение без него.
2. Клиппинг текста при Android fontScale 1.3–2.0 и iOS Dynamic Type (A11Y-19) — нужны скриншоты.
3. Фактический рендер градиентов/скрима над живыми фото (техника) — расчёт worst-case; средние изображения лучше.
4. [WEB]: html lang, focus-видимость (focus ring) в RNW, aria-маппинг accessibilityRole="tab"/"alert", поведение Tab под FeedbackDialog.
5. Адекватность «pill только с иконкой» для когнитивных пользователей (UX-5 решение владельца — здесь не переоцениваем).
6. Порядок объявления при фокусе в ReorderList/draggable-flatlist.
7. Хваткость hitSlop на реальных пальцах/плотных рядах (pips, точки пагинации).
