## Принятые решения владельца (06.10, через выбор в сессии)

- (а) **Офлайн — через `@react-native-community/netinfo`** (новая нативная зависимость). Следствия: правка уходит в `main` как общая (по правилу WEB-CTR-9) и перетекает в `web-port` мержем; поведение NetInfo на RNW (грубее, по `navigator.onLine`) — **не проверено**, проверить на вебе в том же пакете; зависимость требует device-проверки (поставить/собрать) — пункт в чек-листе.
- (б) **Контраст — авто-подбор «ink on primary» по luminance**, палитра акцентов не меняется. Реализация: функция контраста + токен в `src/constants/theme.ts` (по образцу `ON_MEDIA_*`/`ON_ACCENT_TEXT`, введённых CTR-4), точечная подкраска 60+ мест запрещена.
- (в) **QA-1 — полная миграция типов**: `createClient<Database>` + замена рукописных `*Row`/`as unknown as` на сгенерированные `types/database.types.ts`. Это большой diff → делаем после волны 1, по сервисам (supabase client → authService → programsService → workoutService → progressService…), гейты после каждого шага.
- (г) **Волна 1 — по одному пакету**: 1.1+1.2 → gates + прогон → 1.5 → 1.3 → 1.4 (1.4 отдельно, со скриншотами по темам). Не сливать в один коммит.
