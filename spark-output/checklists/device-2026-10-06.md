## A. Накопленные непроверенные пакеты (из `STATUS.md`)

1. **NEOB-1 — анкета при регистрации.** Зарегистрировать новый аккаунт (реальный тест-телефон) → после входа должен открыться онбординг-анкета, а не табы → заполнить или пропустить → вернуться на табы; повторно залогиниться → анкета больше не показывается. Отдельно: правый «Назад»/系统-жест на экране анкеты не должен выкидывать в пустоту.
2. **NEOB-1w — fade онбординга + чистая консоль.** Тот же вход нового аккаунта: переход плавный, в Metro-консоли без новых ошибок/предупреждений.
3. **PRG-400 — программа/фаза в шапке тренировки.** Открыть любую тренировку из активной программы → в шапке имя программы и название фазы (например «PPL 6-day · Гипертрофия») → в Metro нет `400` на `getWorkoutProgramInfo`; карточка рекомендации должна учитывать тип фазы (deload не предлагает «поднимай вес»).
4. **FD-P2d — единицы и КБЖУ.** Профиль → цели: переключение кг/lb меняет подписи нумерики везде, где она показана; плашка КБЖУ на Главной сходится с введённым рационом.
5. **FD-SEED-2a end-to-end (из EDGE-п.8).** Тренировка с «Планка на локтях» → записать «30» в 3 подхода, RPE ≤ 7 → рекомендация должна идти по time-ветке движка (не «поднимай вес»).
6. **«Морфы» (MORF-*).** (а) Инлайн-морфинг таблица ⇄ RPE по 💡 — карточка разворачивается без тёмного оверлея, «Принять» схлопывает; (б) крутилки боли/отдыха; (в) Muscle Map: смена режима/периода кросс-фейдит карту, силуэт не «прыгает»; (г) ThemeAccentSheet: live-preview перекрашивает pill/сеты/чип боли мгновенно, смена темы «перетекает» без скачка.
7. **FX-лист (коммит bce20fa, карта в `STATUS.md` §4).** Лист финиша: мёртвые ячейки пропали, «Info» ведёт туда, где текст; тап по фоновой карточке при открытом листе — ничего не происходит.
8. **PERF-11 — фризы табов.** Быстрое переключение табов подряд (Главная → Тренировки → Программы → Прогресс → Профиль): контент появляется с прелоадером, без секундных «залипаний»; возврат в таб не фризит.
9. **CYC-1/2/3 (календарь цикла).** Отметить событие после 00:00 и до 03:00 — дата не уезжает на «вчера»; лист событий сохраняет отметку на месте.
10. **Release-бандл.** Пункты 3 и 8 прогнать на релизном APK (там был вылет на Главной из-за `rgba(NaN)`).

## B. Находки аудитов, требующие устройства

11. **EDGE-12 — ввод веса.** RU-локаль → ввести «82,5» кг → сверить записанное (сегодня `parseFloat` даёт 82); ввести 99999 → проверить, уходит ли в объём/PR.
12. **EDGE-9 — офлайн-сессия.** Авиарежим на середине тренировки (2–3 записанных сета) → убить приложение → вернуть сеть → открыть: сколько сетов потеряно (сегодня очередь только в памяти — ожидаем потерю; это и есть базлайн до фикса).
13. **EDGE-10 — stale vs error.** Закрыть приложение офлайн >5 мин → открыть: сегодня — полный error-экран.
14. **EDGE-13 — истёкшая сессия.** Дождаться протухания refresh (или перевести время устройства) → должен быть редирект на вход с возможностью восстановиться, а не вечный spinner.
15. **EDGE-1/EDGE-5/EDGE-13 через права.** Deep-link на чужую тренировку/программу (`/workout/<чужой id>`, `/program/<чужой>/edit`) с тест-аккаунта → что показано: «нет доступа» или «Нет тренировок»/«У вас нет активных травм»? Сегодня по коду — правдоподобная пустота.
16. **EDGE-6 — цикл офлайн.** Авиарежим → отметить событие цикла → должен появиться алерт (сегодня тишина), sheet не «съедает» текст ошибки.
17. **EDGE-11 — loading-прыжки.** Троттлинг ~быстрый 3G → экраны «Отчёт тренировки» и «Замеры»: виден ли скачок layout при приходе данных.

## C. Доступность (TalkBack / VoiceOver)

18. **TalkBack/VoiceOver обход шторок.** Открыть любую bottom sheet → свайп-обход: читается ли заголовок, озвучиваются ли live-обновления (единственный live-region в проекте — `SetsGrid.tsx:1228`), произносятся ли `accessibilityValue` степперов; фон под шторкой не должен оставаться в фокусе.
19. **Формы вслух.** Экран «Цели»/регистрация: поле озвучивает label? при ошибке — слышно, что именно не так? есть ли автозаполнение адреса почты (сегодня `autoComplete` нет нигде).
20. **Tost-уведомления.** Сохранить тренировку/цель с включённым TalkBack: озвучивается ли «Сохранено» (live-region в тостах отсутствует).
21. **A11Y-19 — клиппинг текста.** Android fontScale 1.3 → 2.0 (и iOS Dynamic Type largest): пройтись по Главной, тренировке, справочнику, профилю — скриншоты там, где текст обрезан или налез.
22. **Контраст вживую.** Каждая из 5 светлых тем: посмотреть CTA-кнопку, pill активного таба, чипы предупреждения/успеха/ошибки и hero-медию в справочнике — на глаз оценить читаемость (по расчёту neon/orange/blue/pink не проходят AA для белого текста на `primary`).
23. **Reduce motion.** Включить системное «Уменьшить движение» → экран тренировки (пульс таймера отдыха) и скелетоны: сегодня анимации не отключаются ни в одном месте — зафиксировать, насколько дискомфортно (это базлайн до фикса).
24. **Хваткость целей.** Плотные ряды (pips, точки пагинации, компактный таб-бар) большим пальцем на реальном экране — есть ли промахи.
