# Device-чек-лист WARMUP-3ab (разминка: подбор + безопасность)

Замеренное поведение на проде (harness, 40 дней): 5–8 пунктов, ~7 минут, 178 кандидатов в скоринге.
Задача прогона — подтвердить это на устройстве и не словить регресс по фризам/таймеру.

## 1. Настройки → «Порядок разминки»

- [ ] Секция «Предпочтения»: блок «Порядок разминки» с тремя pill (По порядку / Активация / Растяжка), подпись под ним меняется.
- [ ] В секции «Таймер отдыха» тумблера «Активация перед растяжкой» больше нет.
- [ ] Если до обновления тумблер «Активация перед растяжкой» был выключен → после обновления выбрано «Растяжка» (не «По порядку») — поведение не должно меняться молча.
- [ ] Смена порядка → возврат на тренировку → разминка пересобрана в новом порядке (без перезапуска приложения).

## 2. Блок разминки (вкладка «Разминка»)

- [ ] Количество пунктов 5–8 и зависит от дня (короткий день из 3–4 упражнений ≈ 5, тяжёлый день из 8 ≈ 8).
- [ ] Чип «~N мин» показывает 6–9 минут и отличается на разных днях (раньше был вечно «~4 мин»).
- [ ] Секунды на карточках: разогрев 120, активация 60, мобилити 45, статика 40 — суммы сходимся с чипом.
- [ ] В разминке нет упражнения, которое стоит в самом дне (проверить на дне с «Приседания в тренажёре» + активация-упражнением).
- [ ] Для дня на ноги покрыты квадрицепс/бицепс бедра/ягодицы; для дня на плечи — дельты/ротаторная; для «низ груди»/икры подбор вообще не пустой (это был нулевой пересечений случай).

## 3. ⟳ и запомненные замены

- [ ] Тап по ⟳ → набор упражнений изменился (раньше возвращал тот же).
- [ ] Повторное открытие того же экрана без тапа ⟳ → тот же набор (не «прыгает»).
- [ ] Тап по карточке → «Похожие варианты» → «Заменить на …» → упражнение заменено, лист закрыт.
- [ ] Долгий тап по ⟳ → alert «Запомненные замены» → «Забыть» → разминка пересобрана с нуля.

## 4. Травмы (главная проверка пакета)

- [ ] Профиль → Травмы: активная травма «плечо». Открыть разминку → чип «Учтены травмы: Плечо (−N)».
- [ ] Открыть карточку разминки → «Похожие варианты»: ни одного варианта с предупреждением по плечу, внизу списка есть «N скрыто из-за травм».
- [ ] Снять травму → счётчик «N скрыто…» исчезает, список становится длиннее (кэш пересчитался).
- [ ] Травма «высокой степени» на колене → в разминке нет приседаний/выпадов (уровень 2), при этом блок не пустой.

## 5. Регресс-поверхности (не должны сломаться)

- [ ] Таймер карточки: запуск → тик каждую секунду, по окончании — авто-отметка + вибрация; пауза-стоп работает.
- [ ] В фоне (свернуть приложение / убрать вкладку на вебе) остаток не «зависает».
- [ ] Фризы: переход Разминка ⇄ Тренировка, скролл ленты, ввод в сетах — как после FZ-6/PERF-11 (тик разминки по-прежнему в `tickStore`, экран не перерендеривается секундно).
- [ ] Тёмная тема и акценты: чипы/порядок не потеряли контраст (в блоке настроек новый PillToggle использует `onInk`).
- [ ] Долгий тап ⟳ и «Заменить» — на вебе alert появляется (после merge в `web-port`).

## 6. Что считать провалом

- Разминка показывает 7 пунктов по 30 секунд / «~4 мин» → политика секунд не применилась.
- ⟳ даёт тот же набор → сид не участвует в перегенерации.
- В списке вариантов разминки есть упражнение с красным предупреждением по активной травме → фильтр не доехал.
- Существовавший ранее порядок разминки самовольно сменился на «По порядку» → миграция сломана.
