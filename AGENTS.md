## Правило владения

Дубли запрещены: факт живёт в одном документе, в остальных — только ссылка на его ID.

| Документ | Владеет темой | Не должен содержать |
|---|---|---|
| AGENTS.md | точка входа, порядок чтения | правил, статусов, инвентаря |
| CLAUDE.md | правила разработки | инвентарь файлов, статусы, команды, шаблоны кода |
| PROMPTS.md | рецепты и справочники | правила (только ссылки), статусы |
| TASKS_STATUS.md | статусы задач | архитектуру, планы |
| FILE_INVENTORY.md | назначение и долг файлов | статусы (только ID-ссылка) |
| ROADMAP.md | план этапов | статусы и даты выполнения (только ID-ссылка) |
| refactoring_guide.md | архив аудита | что угодно новое |
